# EQ2 Focuser — WiFi-фокусер на ESP8266

Прошивка для беспроводного электрофокусера телескопа на базе ESP8266, совместимая
по протоколу с **MyFocuserPro2** (ASCOM `myFP2ESP` и INDI `myfocuserpro2` драйверы).
Управляет шаговым двигателем 28BYJ-48 через драйвер ULN2003, отдаёт позицию и статус
по TCP (бинарный протокол myFP2) и по HTTP (веб-интерфейс + JSON API).

## Возможности

- Полная реализация числового протокола myFP2 (`:00#` … `:C5#`) поверх TCP, порт `7624`.
- Встроенный веб-интерфейс (мобильный, тёмная тема) на порту `80` с ручным управлением,
  отображением позиции/температуры/RSSI и кнопками OUT/IN.
- OTA-обновление прошивки через [ElegantOTA](https://github.com/ayushsharma82/ElegantOTA).
- Backlash-компенсация (раздельно IN/OUT), 10 позиций пресетов, park/powerdown, регулировка
  скорости и режима шага, сохранение состояния в EEPROM с отложенной (debounced) записью.
- Фолбэк в режим точки доступа (AP), если не удаётся подключиться к домашней WiFi-сети.

## Железо

| Назначение          | Пин ESP8266 |
|---------------------|-------------|
| Мотор IN1           | D5 (GPIO14) |
| Мотор IN2           | D6 (GPIO12) |
| Мотор IN3           | D7 (GPIO13) |
| Мотор IN4           | D8 (GPIO15) |

- **MCU:** ESP8266 (NodeMCU / Wemos D1 mini)
- **Мотор:** 28BYJ-48 (полушаговый режим) через драйвер ULN2003
- Датчик температуры физически не подключён (`tempProbeOK = false`); соответствующие
  команды протокола отвечают заглушками.

## Структура проекта

```
ESP8266_MyFocuserPro2_v2.ino   основная прошивка (TCP/HTTP серверы, протокол, мотор, EEPROM)
html_page.h                    веб-интерфейс, встроенный в прошивку как PROGMEM-строка
myfp2_protocol_commands.txt    справочник по всем командам протокола myFP2
secrets.h.example              шаблон для WiFi-учётных данных
secrets.h                      (не в git) реальные WiFi SSID/пароль — создаётся локально
```

## Настройка и прошивка

1. Установить в Arduino IDE (или PlatformIO) поддержку платы **ESP8266** и библиотеки:
   `ESP8266WiFi`, `ESP8266WebServer`, `ElegantOTA`, `EEPROM` (входит в ядро ESP8266).
2. Скопировать `secrets.h.example` → `secrets.h` и указать свои данные:
   ```cpp
   #define WIFI_SSID     "..."
   #define WIFI_PASSWORD "..."
   #define AP_SSID       "FocuserAP"
   #define AP_PASSWORD   "..."
   ```
   `secrets.h` добавлен в `.gitignore` и не должен коммититься.
3. При необходимости скорректировать `deviceName`, `tcpPort` и пины мотора в начале
   `ESP8266_MyFocuserPro2_v2.ino`.
4. Прошить плату. При первом запуске EEPROM инициализируется значениями по умолчанию
   (`maxStep = 8000`, `stepMode = 2` и т.д.).
5. Если подключение к WiFi не удалось за 40 попыток (~20 c), контроллер поднимает точку
   доступа `FocuserAP` для аварийного доступа к веб-интерфейсу.

Последующие обновления прошивки можно заливать по воздуху через `/update` (ElegantOTA),
без физического подключения к плате.

## Веб-интерфейс и REST API

Открывается по адресу `http://<IP-контроллера>/`.

| Метод/путь         | Параметры   | Действие                              |
|---------------------|-------------|----------------------------------------|
| `GET /`             | —           | HTML-страница управления               |
| `GET /status`       | —           | JSON: позиция, цель, движение, скорость, температура, maxStep, RSSI, IP |
| `GET /moveto`       | `pos`       | Переместить на абсолютную позицию      |
| `GET /step`         | `steps`     | Переместить на относительное число шагов |
| `GET /stop`         | —           | Остановить движение                    |
| `GET /zero`         | —           | Обнулить текущую позицию               |
| `GET /home`         | —           | Переместиться в позицию 0              |
| `GET /save`         | —           | Сохранить состояние в EEPROM           |
| `GET /reset`        | —           | Сбросить настройки к значениям по умолчанию |
| `GET /setspeed`     | `us`        | Задержка между шагами, мкс (600–5000)  |

## TCP-протокол (порт 7624)

Совместим с ASCOM `myFP2ESP` и INDI `myfocuserpro2`. Команды имеют вид `:NN[аргумент]#`,
ответы — `<токен><значение>#`. Полный список поддерживаемых команд (`:00#`…`:C5#`,
включая расширенные `:A0#`–`:C5#`) — в [`myfp2_protocol_commands.txt`](myfp2_protocol_commands.txt).
На ESP8266 часть команд (LED-индикаторы, Nextion-дисплей, TMC-драйверы, Alpaca/Management
серверы) не поддерживается аппаратно и возвращает заглушки/нули.

## Безопасность

WiFi-учётные данные вынесены в `secrets.h` (гитигнорится); в репозитории хранится только
шаблон `secrets.h.example`. TCP- и HTTP-серверы не имеют аутентификации — предполагается
использование в доверенной домашней сети.
