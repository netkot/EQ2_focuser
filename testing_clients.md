# Проверка фокусера в астрономических программах

Обычные планетарии (Stellarium, Cartes du Ciel) фокусером не управляют, они работают только с монтировкой. Проверить фокусер можно двумя путями.

## 1. KStars + Ekos (INDI)

Это единственный планетарий со встроенным управлением фокусером.

- В профиле Ekos выберите драйвер **MyFocuserPro2**. На вкладке Connection укажите подключение по сети: `192.168.0.80`, порт `7624`.
- В модуле Focus есть кнопки In/Out, переход на абсолютную позицию и автофокус.
- INDI-сервер работает на Linux или Mac, в том числе на Raspberry Pi или в StellarMate. Под Windows KStars может подключиться только к удалённому INDI-серверу.

## 2. Windows: ASCOM-драйвер + программа съёмки

Это проще.

- Поставьте **ASCOM Platform** и **ASCOM-драйвер myFP2ESP** от автора MyFocuserPro2 (Robert Brown). В настройках драйвера выберите TCP/IP, `192.168.0.80:7624`.
- Дальше подойдёт любая программа с поддержкой ASCOM-фокусеров:
  - **N.I.N.A.** — бесплатная, есть панель фокусера и автофокус. Для проверки, пожалуй, удобнее всего.
  - **SharpCap** — удобна для визуальной фокусировки по живой картинке.
  - **APT**, **SGP**.
- **Conform Universal** (утилита ASCOM) прогоняет автоматический тест драйвера на соответствие стандарту. Так видно, правильно ли прошивка отвечает на команды.

## Учтите при проверке

- Когда фокусер едет из клиента, следите за веб-интерфейсом на `http://192.168.0.80/`: позиция и схема трубы должны меняться синхронно.
- **Reverse direction** в клиенте или драйвере оставьте выключенным. Правильная полярность мотора зашита в прошивку (`MOTOR_DIR_INVERT`), а клиентский реверс только переворачивает её дополнительно.
- В клиенте должен получиться максимум **9000**. Если клиент предлагает задать свой Max Step, оставьте 9000.
- TCP-протокол доступен одному клиенту за раз, но веб-интерфейс работает параллельно с ним.
